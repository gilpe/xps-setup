# XPS Setup

Customizing a new Arch Linux installation on an old laptop from scratch

Hardware: Dell XPS 13 9350 (i7-6500U, 16 GiB RAM, QHD+ touchscreen) —
verified inventory in HARDWARE.md.

## Repository layout

- SPECS.md — project requirements (source of truth)
- AGENTS.md — operating guide for AI agents
- STATUS.md — progress log
- HARDWARE.md — verified hardware inventory and base-system baseline
- install.sh — system provisioning (packages, services, system files)
- dotfiles/ — application configuration (created as modules progress)
